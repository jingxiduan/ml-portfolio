## 1. 一句话：这个项目在干什么

把 **DiffusionOPSD**（本来做图像像素扩散的 on-policy self-distillation）
**迁移到"数字人动作"上**：冻结 JoyVASA 的 audio→73 维动作扩散模型（LoRA 微调），
用一个**可微的"生动度"reward** 做 post-train，让生成的数字人会眨眼、点头、视线变化，
而不是一张僵住的面具。渲染器是 LivePortrait（不训练）。

- 方法来源：https://github.com/worldbench/DiffusionOPSD（**只迁移方法**，不是它的底模）
- 底模：JoyVASA `motion_generator_hubert_chinese`（冻结）
- 渲染：LivePortrait（warp + stitching + pasteback）
- 三个目标行业：**finance / real-estate / short-video**，每个行业的动作目标都从
  **真人公开视频里量出来**，不是拍脑袋调的。

**诚实边界**：这是方法项目，不是量产数字人视频。目前**只跑过一次 600 步 smoke 训练**。

## 6. 怎么复现

```bash
cd 07-talking-head-motion-opsd
source .venv/bin/activate            # 环境：见 scripts/h20_render_setup.sh

# 1) 环境（下载 JoyVASA / LivePortrait / HuBERT-chinese，约 2.5GB）—— third_party 未入库
bash scripts/h20_render_setup.sh

# 2) 训练数据（audio_public 未入库，需重建）
python scripts/build_audio_segments.py --n-train 2000 --n-eval 100

# 3) 量三个行业的真人动作带
python scripts/calibrate_industry_bands.py      # -> outputs/industry_bands.json

# 4) 训练（本次 smoke：lr 1e-4 + 200 步 warmup）
CUDA_VISIBLE_DEVICES=0 python src/opsd_train_motion_v5.py \
  --out outputs/opsd_v5_finance_smoke --data-dir data/audio_public/train \
  --rounds 600 --lr 1e-4 --warmup 200 \
  --amp-target-deg 1.384 --amp-tol-deg 1.0 --jitter-cap-deg 0.188 --blink-target-mean 0.12

# 5) 真人驱动 demo（顶部那一块）
python scripts/render_real_driven.py --video <clip> --portrait auto
python scripts/postprocess_video.py <in>.mp4 <out>_hq.mp4 --sr none
python scripts/build_demo_sbs.py --tag f3 --industry finance \
  --base ..._base_hq.mp4 --real ..._real_hq.mp4

# 6) 两人格 demo（中部那一块）
python scripts/check_persona_clips.py && python scripts/add_gaze_checks.py
python scripts/build_persona_grid.py
```

## 7. 全量备份（2026-11-02，已全部 push）

| 内容 | 大小 | 方式 |
|---|---|---|
| 代码 / 脚本 / docs / logs | ~2MB | 直接入库 |
| 所有 demo 成品（demos / persona_grids / real_driven / industry_demo_v3 / tier2） | ~1.3GB | 直接入库 |
| `data/`：精选人像 + 人声 + 公开视频 + 全部 manifest | ~150MB | 直接入库 |
| `data/audio_public/`：AISHELL 源 tar + 解压 wav + 2000 训练窗口 + eval | **6.8GB** | 直接入库（单个文件都 <100MB），分批 push |
| `third_party/`：第三方代码 + 权重 | **2.8GB** | 代码和小权重直接入库；**9 个 >100MB 的权重切成 90MB 分块**放 `backups/weights_chunks/`（带 sha256 清单） |

**为什么有权重要切块**：GitHub 对单个文件有 **100MB 硬限制**（不用 LFS 就传不上去），
而 LFS 免费额度只有 1GB，装不下。所以把 9 个大权重（最大 1,084MB）切成 90MB 的块。

恢复方式：

```bash
bash scripts/restore_chunks.sh     # 把分块拼回 third_party/JoyVASA/pretrained_weights/...
```

**唯一没上传的**：`.venv/`（6.8GB，Python 虚拟环境）——它是环境不是资料，
用 `scripts/h20_render_setup.sh` + `requirements` 重建即可。
